# Homebrew tap for DIAspeXtract

```bash
brew install okohlbacher/diaspextract/diaspextract
```

Installs the prebuilt release bundle of [DIAspeXtract](https://github.com/okohlbacher/diaspextract) (macOS arm64/x64,
Linux arm64/x64). The formula is updated by the release workflow of the main repository; do not edit its version,
URLs or checksums by hand.
